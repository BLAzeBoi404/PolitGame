# SOVEREIGN — Государство 0.3

Офлайн-стратегия для Windows: 176 стран и территорий, 4 136 областей, экономика, исследования, дипломатия и сухопутные кампании. Обновление 0.3 связывает разработку техники с промышленностью и оснащением армии.

## Запуск готовой игры

Скачайте [`releases/Sovereign-0.3-windows.zip`](releases/Sovereign-0.3-windows.zip), распакуйте в отдельную папку и запустите **Sovereign.exe**. Нужна Windows 10/11 с .NET Framework 4.7.2 или новее. Для игры не нужны сервер, аккаунт и интернет.

Для переноса кампании скопируйте свою папку `Saves` рядом с новым exe. Сначала сохраните отдельную копию: версия 0.3 читает старые сохранения и переводит их в формат 2; версия 0.2 новый формат не читает. Личные сохранения из предоставленного ZIP в Git не включены.

## Что изменилось

- **Конструктор:** танки, БМП/БТР, грузовики, артиллерия, истребители, бомбардировщики, разведывательная и транспортная авиация; восемь групп модулей, совместимость, технологические ограничения, название и сравнение с выбранной моделью.
- **Производство:** каталог независимых проектов, оплачиваемые испытания, конечные серийные заказы, распределение заводов, эффективность, реальные расходы денег и материалов, пауза, архив моделей и склад готовых комплектов.
- **Армия:** набор только из произведённых комплектов, 30 дней подготовки, перевооружение и до трёх разных групп поддержки. Освоение новой техники занимает 14 дней. Танки, БМП и артиллерия могут быть основой части; авиация и грузовики используются как поддержка.
- **Бой и снабжение:** броня и пробитие влияют на результат; бомбардировщики и разведка усиливают огонь, истребители противодействуют авиации, транспорт помогает снабжению. Сухопутная связь с главным домашним регионом, запас автономности и потери при окружении.
- **ИИ:** собственные проекты, реальные производственные заказы и набор из запасов; переброска к границам, оценка сил перед атакой и восстановление ослабленных частей.
- **Карта:** семь режимов, подсветка области под курсором, полный оставшийся маршрут, различение нейтральных и вражеских армий. География кэшируется отдельно от движущихся объектов.
- **Надёжность:** проверка содержимого сохранений, миграция старого формата, атомарная запись с резервной копией, воспроизводимое продолжение кампании и автоматические проверки интерфейса.

## Первые шаги

1. Выберите страну. Игра начинает на паузе; **Пробел** включает время.
2. В **Конструкторе (8)** выберите класс и модули. Дайте проекту новое имя и оплатите испытания. Зелёного «максимума во всём» нет: броня добавляет массу, сложность увеличивает цену и требования к обслуживанию.
3. В **Производстве (4) → Серии и склад** выберите проект, число заводов и комплектов. Нужны сталь, машины, вооружение и деньги. Подсказка линии объясняет остановку.
4. При нехватке заводов откройте вкладку **Предприятия** и постройте оборонный завод. Начальная эффективность линии — 25%; она растёт только при фактической работе.
5. После поставки откройте **Армию (7)**: наберите часть либо перевооружите существующую. Выбранный в каталоге проект определяет выдаваемую технику. Для поддержки выберите соответствующий класс.
6. Подготовленные части выбираются на карте; ПКМ по области задаёт маршрут. Нейтральные границы закрыты. Окружение истощает снабжение.

**Клавиши:** 1–9 — основные разделы, F5/F9 — сохранить/загрузить, F11 — полноэкранное окно, Home — своя страна, Esc — меню с паузой, колесо — масштаб карты или прокрутка списка. Управление пока фиксированное.

## Сборка и тестирование

Сохранён C# / Windows Forms / GDI+. Карта и иллюстрация встроены в исполняемый файл. Новых библиотек времени исполнения нет.

**Windows, .NET SDK 8:**

```powershell
./scripts/build-windows.ps1
# результат: bin/Release/net472/Sovereign.exe
```

**Linux, Mono, libgdiplus и Xvfb:**

```bash
bash scripts/test.sh --ui
# build/Sovereign.exe; отчёты и снимки — artifacts/
```

**Эта облачная среда (Debian 13, без root):**

```bash
bash scripts/setup-cloud.sh
bash scripts/test.sh --ui
source /workspace/tooling/env.sh
bash scripts/with-display.sh mono build/Sovereign.exe
```

`--test <отчёт.txt>` проверяет симуляцию без дисплея; `--ui-test <папка>` открывает настоящее окно и проверяет действия и раскладку. `--verify-save <файл.xml>` загружает сохранение и проверяет 30 дней продолжения, не записывая исходный файл. `--preview Серии <файл.png>` создаёт контрольный кадр.

Отчёты выполненных проверок: [docs/validation](docs/validation). CI описан в [build.yml](.github/workflows/build.yml); локальная проверка не означает, что удалённый CI уже прошёл.

## Границы версии

Это развитие существующей игры, а не реализация всего многолетнего ТЗ. Авиация пока действует как поддержка наземных частей: нет самостоятельных воздушных миссий, аэродромов и воздушных зон. Нет флота, морских перевозок, системы фронтовых приказов, исторических карт, глубокой политической модели и многосторонних мирных переговоров. Население и ресурсы регионов — оценки; действующие войны реального мира не моделируются.

Комплект техники — абстракция оснащения одной части, а не поштучный парк машин. Пополнение людского состава отдельно не учитывается. Серийные испытания оплачиваются сразу. Дальность самолётов — расчётный параметр; для транспорта она участвует в бонусе снабжения, отдельных дальностей воздушных миссий пока нет. Правила и дальнейшие приоритеты описаны в [docs/DESIGN.md](docs/DESIGN.md).

Исходники восстановлены из предоставленного пользователем `Sovereign-0.2.exe`: [происхождение](docs/PROVENANCE.md). Документы 0.2 сохранены в `docs/archive-0.2` как архив, а не актуальный отчёт о тестах.
