# Происхождение проекта

Пользователь предоставил Sovereign.zip с Windows-сборками 0.1, 0.1.1 и 0.2, документацией, настройками, изображением и личным сохранением. Исходников C# в архиве не было. Репозиторий BLAzeBoi404/PolitGame был пустым.

Рабочая основа восстановлена из Sovereign-0.2.exe через ILSpyCmd 9.1.0.7988 с ссылками на библиотеки .NET Framework из Mono 6.12. Сохранены существующие классы, карта, интерфейс и встроенные тесты. Комментарии и исходные имена некоторых локальных переменных в бинарной сборке отсутствовали; они не выдаются за восстановленные оригиналы.

SHA-256 исходной сборки 0.2: `58c2dfb039ad053edc2c8eea95bbfbce789e10085c06122e239584038c48a68a`.

Первый коммит фиксирует восстановленную основу. Её отдельная Mono-сборка прошла все 27 встроенных проверок и 818 игровых дней перед дальнейшими изменениями. Последующие коммиты содержат обновление 0.3.

`assets/world.bin` и `assets/tank.png` извлечены из встроенных ресурсов 0.2; `assets/app.ico` — из значка программы. География — Natural Earth, public domain (см. архивный файл ИСТОЧНИКИ.txt). Согласно предоставленной документации, иллюстрация танка создана через imagegen; исходный файл с запросом не присутствовал в ZIP. Новые схемы других классов техники нарисованы кодом этого проекта.

Личные Saves/autosave.xml, резервная копия, settings.xml и старые exe не опубликованы. Исходный ZIP и сохранение остаются вне рабочего Git-каталога. Упомянутые коммерческие игры используются как ориентиры требований; их код и ресурсы не добавлялись.
