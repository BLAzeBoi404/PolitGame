# Проверки Sovereign 0.4

Проверен исполняемый файл Release/net472, собранный .NET SDK 8.0.426. Фактическое исполнение: Debian 13, Mono 6.12, libgdiplus и Xvfb. На реальном Windows эта сессия игру не запускала; удалённый GitHub Actions не считается пройденным по локальным результатам.

- 126 проверок логики, `Failures: 0`: техника и производство, деньги и материалы, война и договоры, доступ и снабжение, мир и перемирие, фронты, ручное управление, формат сохранений, клавиши и многолетняя симуляция.
- 107 проверок интерфейса, `Failures: 0`: настоящее окно WinForms, события мыши и клавиатуры, работающие производственные/дипломатические/фронтовые кнопки, 14 экранов при 1280×720, 1600×900 и 1920×1080, семь режимов карты, кэш и переназначение управления. Это автоматическая проверка и просмотр контрольных кадров, не длительная ручная игровая сессия.
- Сохранение из исходного пользовательского архива загружено и продолжено на 30 дней. Исходный файл не перезаписывался.
- Сборка без предупреждений и ошибок. SHA-256 exe и входных файлов записаны в `build-receipt.json`; упаковщик отклоняет несовпадающий бинарный файл или изменённые после проверки исходники.

## Замеры до и после

Один и тот же хост и Mono; результаты отдельных прогонов, не гарантированная производительность всех компьютеров. Исходная версия — коммит `31b4dd7`. Графические проверки выполнены при 1600×900: 30 обычных кадров, 12 перестроек и 20 кадров перетаскивания. В 0.4 перестройка дополнительно рисует 128 пикселей за каждым краем карты.

| Измерение | 0.3 | 0.4 |
|---|---:|---:|
| Полная перестройка карты после сдвига камеры | 154,5 мс | 79,8 мс, включая запас |
| Обычный кадр карты | 7,5 мс | 7,5 мс |
| Кадр перетаскивания | 7,3 мс | 7,5 мс |
| Небольшой сдвиг после отпускания мыши | новая растеризация | точный запас изображения, без растеризации |
| 1 825 дней / 176 стран / 4 136 областей / 592 части | 4,66 с | 3,69 с |
| Размер exe | 5 104 128 байт | 3 019 776 байт |

Симуляция использует одинаковый встроенный сценарий; исходная 0.3 собрана Mono, финальная 0.4 — SDK. Эти замеры дают ориентир, а не чистое сравнение компиляторов или универсальное ускорение. Синхронная перестройка после большого скачка камеры всё ещё может быть заметна. Обычный кадр и кадр перетаскивания не выдаются за скорость полной растеризации.
