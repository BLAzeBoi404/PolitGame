# Проверки Sovereign 0.7

Проверен именно `bin/Release/net472/Sovereign.exe`, собранный .NET SDK 8.0.426 без ошибок и предупреждений. Исполнение — Debian 13 / Mono 6.12 / libgdiplus / Xvfb. Реальный Windows 10/11 в этой сессии не использовался; удалённый GitHub Actions не считается пройденным по локальным результатам.

- **257 проверок логики**, `Failures: 0`: прежние экономика, производство, договоры, фронты, авиация, личный состав и сохранения. Новые проверки покрывают цены, отсутствие списаний при отказе, два одновременно действующих решения, точные сроки и повторное принятие, настоящие изменения выпуска/сборки/исследований/налогов, заём и проценты, все шесть семейств событий, расходы запасов, реальный бытовой спрос при нормировании, бесплатный вариант при просрочке, однократное применение, торговые и научные условия, ИИ и двухлетнюю политическую симуляцию.
- **184 проверки интерфейса**, `Failures: 0`: реальные события мыши и клавиатуры WinForms на 1280×720, 1600×900 и 1920×1080. Новые проверки открывают кабинет, принимают программу с оплатой, блокируют повторное списание, проверяют однократную остановку ускорения, вкладки, недоступные варианты, оплату решения события, историю и возврат к бюджету. Две реальные серии проверены на отсутствие пересечения с новой кнопкой в боковой панели. Длинный список мер проверен прокруткой.
- Исходное пользовательское сохранение из ZIP и тестовая кампания версии 0.6 с личным составом загружены, мигрированы и продолжены на 30 дней. Исходные файлы не перезаписывались. Миграция формата 5 сохраняет деньги, людей и генератор случайных чисел и не выдаёт бесплатные меры.
- После сохранения ожидающего события, выбора одного ответа и следующих 150 дней получены побайтово одинаковые файлы всей кампании. Повреждённые сроки и политическая повестка отклоняются до замены работающей кампании.
- Многолетний сценарий: `1825 days, 176 countries, 4136 provinces, 575 formations: 4.15 seconds`; итоговое состояние проходит валидацию. Это встроенный сценарий, не предел производительности масштабной войны.
- Вручную просмотрены ведомость программ, событие и действующие меры, включая 720p и прокрученный длинный список. Длительное игровое балансирование и проверка на настоящем Windows остаются необходимыми этапами.

## Измерение карты

1600×900, Mono/Xvfb:

| Операция | Среднее время |
|---|---:|
| Обычный кадр, 30 кадров | 10,7 мс |
| Перетаскивание кэшированной карты, 20 кадров | 10,9 мс |
| Полная перестройка с запасом 128 px, 12 кадров | 140,7 мс |

Список владельцев территорий для событий собирается одним недельным проходом; коэффициент сборки рассчитывается один раз на страну за день. Прежний кэш карты сохранён. Полная растеризация большого перемещения остаётся синхронной. Измерения сделаны в облачной среде с параллельными проверками; они не являются контролируемым сравнением скорости версий. Политика меняет поведение ИИ и конечное число частей.

Отчёты: `tests-sdk.txt`, `ui-results.txt`, `build-sdk.txt`, `legacy-save.txt`, `previous-release-save.txt`, `simulation-performance.txt`. Хеши точной сборки и её исходников — `build-receipt.json`; упаковщик проверяет совпадение перед выпуском. XML-сценарии сохраняются только в игнорируемой папке `artifacts/`.
