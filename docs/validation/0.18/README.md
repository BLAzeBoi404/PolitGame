# Проверка SOVEREIGN 0.18

Release `net472`, .NET SDK 8.0.426; дополнительная сборка через Mono. Контрольные суммы exe, исходников и библиотек находятся в [build-receipt.json](build-receipt.json). Упаковщик проверяет соответствие архива испытанной сборке и исключает пользовательские сохранения и настройки.

## Функциональные проверки

| Проверка | Результат |
| --- | --- |
| Полная логика и длительные кампании | 736 PASS, 0 FAIL — [отчёт](tests-sdk.txt) |
| Интерфейс, мышь, клавиатура, три размера окна | 602 PASS, 0 FAIL — [отчёт](ui-results.txt) |

| Сохранение исходной 0.16 после 765 дней + 30 дней | PASS — [отчёт](legacy-save.txt) |

Новые проверки проверяют реальные последствия действий: выбор слоя и отсутствие прохода щелчков сквозь меню; закрытие через Esc; Tab, Shift+Tab, Enter и приоритет переназначенной клавиши; сохранение свёрнутой сводки и освобождение карты; фильтры внимания/обучения, порядок готовности, прокрутку списка и пустые результаты; запрет обучения при нехватке топлива; безопасное нажатие на информационную карточку; развёрнутую подсказку в пределах окна.

Группировка войск сохраняет весь личный состав, скрывает неразрешённые иностранные позиции, повторно использует группы при панорамировании и возвращает настоящую часть при приближении. Проверки разведки 0.17 выполняются на всех семи слоях и двух масштабах. Новая группировка — отображение; численность и размещение соединений в кампании не меняются.

GPU-проверки подтверждают сохранение команд мира и плиток при наведении между кнопками, открытии списка слоёв, перемещении фокуса и сворачивании сводки. Уход курсора с подсвеченной области по-прежнему обновляет её выделение. При заблокированном работнике симуляции информационная карточка не добавляет пустое действие, а колесо ведомости готовности ждёт завершения дня, не читая изменяемый список армии. После публикации дня прокрутка выполняется. Состояние фонового дня по-прежнему совпадает с синхронным движком.

Просмотрены снимки [карты](modern-map.png), [слоёв](modern-layers-1600.png), [готовности на 1280](modern-readiness-1280.png), [подсказки](modern-tooltip.png), [конструктора](modern-designer.png), [экономики](modern-economy-1280.png). Рядом сохранены варианты слоёв и готовности на 1280×720, 1600×900, 1920×1080 и [GPU-ведомость](gpu-readiness.png). Многолетние логические проверки не заменяют длительную ручную оценку игрового баланса.

## Время кадра

Один и тот же внешний обработчик `scripts/military-map-probe.py` запускает исходный exe из архива 0.17 и итоговый exe 0.18. Одинаковая сцена, военный слой, 1600×900, высокая детализация, запрошено 165 кадров/с; ввод до 500 событий/с с объединением очереди. Два прохода по шесть секунд: первый и повторный. Прогоны выполняются последовательно, после всех функциональных тестов.

Стенд — Linux, Mono, Xvfb, **Mesa llvmpipe**, два потока программной растеризации. Интервалы означают презентацию в виртуальном окне, не частоту физического монитора. Для каждого сочетания версии/режима выполнен один прогон; это наблюдения, а не аппаратная гарантия.

| Повторный проход: среднее / p95 / максимум, мс | 0.17 | 0.18 |
| --- | ---: | ---: |
| Масштаб 45, пауза | 14,15 / 16,06 / 30,58 | 14,91 / 18,10 / 26,62 |
| Масштаб 45, симуляция 7× | 16,57 / 24,39 / 33,20 | 16,23 / 23,73 / 32,69 |
| Масштаб 14, пауза | 14,10 / 16,25 / 27,93 | 13,92 / 16,25 / 24,67 |

В обзорной сцене число известных групп уменьшилось с **25 до 5** без изменения суммарного личного состава. Во всех повторных проходах — ноль новых плиток и ноль возвратов к обзорному атласу. На паузе также ноль загрузок текстур и ноль сборок HUD. В работающей симуляции 0.18 выполнила 49 сборок HUD и 83 загрузки против 42 и 70 у 0.17; обе версии один раз открыли событие, за полный прогон прошли 87 и 89 дней соответственно.

На среднем масштабе на паузе средний интервал и p95 в этой паре выросли; в живом режиме и на обзоре результаты близки. Поэтому общее ускорение панорамирования не заявляется. Подтверждены уменьшение числа обзорных маркеров и отсутствие пересборки мира от изменения оформления. На первом проходе обзорной сцены 0.18 один кадр использовал резервный обзорный атлас; первичная загрузка деталей остаётся асинхронной. Ни один из этих замеров не подтверждает аппаратные 165 FPS.

Полные пары: [0.17 пауза](map-0.17-paused-165.txt) / [0.18 пауза](map-0.18-paused-165.txt), [0.17 симуляция](map-0.17-live-165.txt) / [0.18 симуляция](map-0.18-live-165.txt), [0.17 обзор](overview-0.17-paused-165.txt) / [0.18 обзор](overview-0.18-paused-165.txt).

Полные отчёты сохраняют оба прохода, максимальные задержки, новые плитки, загрузки текстур, GC, число изменённых кадров и прошедших дней. Нулевые новые плитки означают повторное использование уже посещённого участка, а не отсутствие загрузки при любом переносе камеры. Симуляция не менялась в этом этапе; новые замеры расчёта дня не заявляются. Проверка Windows 10/11 с физической видеокартой пользователя остаётся необходимой для оценки 60–165 FPS.

## Воспроизведение

```bash
source /workspace/tooling/env.sh
bash build.sh
DOTNET_CLI_HOME=/workspace/tooling/dotnet-home NUGET_PACKAGES=/workspace/tooling/nuget /workspace/tooling/dotnet/dotnet build Sovereign.csproj -c Release
mono bin/Release/net472/Sovereign.exe --test artifacts/logic/tests-sdk.txt
bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --ui-test artifacts/ui
MESA_SHADER_CACHE_DIR=/tmp/sovereign-mesa-cache LP_NUM_THREADS=2 bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --gpu-test artifacts/gpu
python3 scripts/military-map-probe.py artifacts/probe/Probe.cs
python3 scripts/military-map-probe.py artifacts/probe/Overview.cs --overview
```

Сборка и запуск внешнего измерителя описаны в начале `scripts/military-map-probe.py`. Используйте абсолютные пути к exe и отчёту, `--165`, затем отдельный прогон с `--live`. Не запускайте измерения параллельно с тестами. Native Windows и аппаратный OpenGL в этой среде не проверялись.
