# Проверки Sovereign 0.11

Проверен именно `bin/Release/net472/Sovereign.exe`, собранный .NET SDK 8.0.426 / Release net472 без ошибок и предупреждений. Исполнение — Debian 13 / Mono 6.12 / libgdiplus / Xvfb. Реальный Windows 10/11 и удалённый GitHub Actions в этой сессии не проверены. Хеши исполняемого файла и соответствующих исходников: [build-receipt.json](build-receipt.json).

## Функциональные результаты

- **493 проверки логики**, `Failures: 0`. Прежние системы и оплачиваемые государственные реформы: нейтральная исходная форма, условия старта, начальная цена и политические издержки, запрет параллельных проектов, реальные ежедневные шаги, пауза, кризис, война, давление и отсутствие территории.
- Все четыре формы достигнуты через подготовку, выбор и внедрение. Оба варианта принятия проверены на точных границах сроков. Повестка открывается после 45 рабочих дней, истекает через 21 день; годовой срок сохраняется при отзыве. Долго приостановленная реформа может завершиться после истечения её исходного годового срока и не блокирует следующий проект ошибочно.
- Проверены реальные выпуск и налоги, недельные исследования, целевые одобрение и стабильность, сборка с расходом стали, сочетание временных государственных издержек с программами кабинета. Пауза сохраняет издержки; отзыв снимает их. Более быстрые учреждения не создают технику без материалов.
- **454 проверки интерфейса**, `Failures: 0`. Настоящие события мыши WinForms; четыре формы, подготовка, повестка и внедрение проверены при 1280×720, 1600×900 и 1920×1080. Проверены границы и отсутствие пересечения кнопок, переходы, оплата, пауза, отзыв, реакция на принятие и отказ в подтверждении, автоматическая однократная пауза при новой повестке и напоминание в текущих делах. Ответы системных подтверждений задаёт тестовый обработчик; внешний вид этих модальных окон не проверялся.
- Все три этапа сохраняются побайтово вместе с оплатой, датами и паузой. Два экземпляра остаются одинаковыми после 150 настоящих мировых тиков. Неизвестные формы/этапы, несогласованная оплата, неверные даты и остаточные данные отклоняются до замены кампании.
- Миграция формата 9 в 10 сохраняет научный прогресс, деньги, доктрины и RNG, выдавая только нейтральные институты. Исходное пользовательское сохранение из ZIP и сохранение 0.10 с доктринами загружены и продолжены на 30 дней; оригиналы не перезаписаны. XML-тесты и личные сохранения в Git и релиз не входят.
- ИИ оплачивает подготовку и согласование, проходит внедрение и не принимает решения за игрока. Двухлетний сценарий проверяет завершённые реформы у нескольких стран и ограниченный размер политической истории. Пятилетний общий сценарий: `1825 days, 176 countries, 4136 provinces, 566 formations: 5.32 seconds`. Его время получено одновременно с функциональными UI-проверками, поэтому не служит сравнением скорости версий.

## Проверка производительности

Сначала сохранён отдельный отчёт [performance.txt](performance.txt). В нём наблюдался больший разброс: полная перестройка карты в среднем 43,79 мс, семь тиков с кадром — 49,34 мс. Отчёт сохранён, а различие проверено последовательным запуском двух версий без параллельных тестовых задач.

База — **точный ранее проверенный exe 0.10**, извлечённый из релизного ZIP; его хеш совпадает с квитанцией 0.10. Затем запущен проверенный exe 0.11. Обе сборки .NET SDK 8.0.426 / Release net472, один измерительный модуль, одно разрешение 1600×900 и одинаковая начальная камера. Выполнена одна последовательная пара; это ограниченный диагностический замер, а не статистическое доказательство ускорения.

| Сценарий | 0.10, среднее мс | 0.11, среднее мс | 0.11, p95 мс |
|---|---:|---:|---:|
| Кэшированный политический кадр | 3.65 | 3.47 | 4.10 |
| Наведение с точным попаданием | 3.65 | 3.60 | 4.08 |
| Выделенная сложная область | 13.46 | 13.21 | 13.90 |
| Перетаскивание карты | 3.67 | 3.56 | 4.00 |
| Полная перестройка карты | 35.14 | 36.62 | 41.47 |
| Ресурсный слой при смене дня | 6.22 | 6.28 | 11.77 |
| Семь тиков симуляции и кадр | 23.28 | 26.50 | 39.55 |
| Научная ведомость | 6.24 | 6.81 | 10.73 |


Карта в этой паре осталась в сопоставимом диапазоне. Синтетический расчёт семи дней стал дольше на 3,22 мс в среднем; он включает новые государственные процессы и различающиеся решения ИИ. Рабочий таймер по-прежнему выполняет максимум один день за вызов. Полная перестройка карты существенно дороже сохранённого кадра и остаётся направлением дальнейшей оптимизации.

Это **CPU-время ввода и отрисовки под Mono, не измерение FPS на Windows**. Условия облачного процессора влияют на разброс; большие войны и реальные пользовательские машины требуют отдельного профилирования. Полные отчёты: [0.10](performance-before.txt), [0.11](performance-after.txt).

## Воспроизведение

```bash
dotnet build Sovereign.csproj -c Release
source /workspace/tooling/env.sh
mono bin/Release/net472/Sovereign.exe --test artifacts/test-sdk-0.11/tests-sdk.txt
bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --ui-test artifacts/ui-sdk-0.11
# Отдельно, после завершения тяжёлых задач:
bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --benchmark artifacts/performance.txt
```

`scripts/package.py` сверяет SHA-256 exe и исходников с квитанцией, требует успешные отчёты и проверяет CRC архива. Это не завершение всего ТЗ; оставшиеся механики перечислены в [REQUIREMENTS-STATUS.md](../../REQUIREMENTS-STATUS.md).
