# Проверки Sovereign 0.5

Проверен именно `bin/Release/net472/Sovereign.exe`, собранный .NET SDK 8.0.426 без ошибок и предупреждений. Исполнение — Debian 13 / Mono 6.12 / libgdiplus / Xvfb. Реальный Windows 10/11 в этой сессии не использовался; удалённый GitHub Actions не считается пройденным по локальным результатам.

- **158 проверок логики**, `Failures: 0`: прежняя экономика, производство, оснащение, договоры, фронты и сохранения; дополнительно аэродромы, реальные произведённые самолёты, подготовка, ограничения класса и дальности, топливо, перехват, удары, разведка, расход грузов снабжения, ремонт, перебазирование, потеря баз, воздушный ИИ и миграция формата 3 → 4.
- **151 проверка интерфейса**, `Failures: 0`: настоящие события мыши и клавиатуры WinForms, три разрешения (1280×720, 1600×900, 1920×1080), компактные панели и подробные ведомости, семь слоёв карты, кэш, настройка клавиш, выбор страны на карте, медленное перетаскивание без ошибочного выбора, привязка масштаба к курсору, восстановление камеры при отмене старта, действия авиационной панели.
- Исходное пользовательское сохранение из ZIP загружено, мигрировано в памяти и продолжено на 30 дней. Исходный файл не записывался.
- Многолетняя проверка: 1825 дней, 176 стран, 4136 областей, 600 наземных частей — 3,40 с на этом хосте; итоговое состояние проходит полную валидацию. Это измерение встроенного сценария, а не предел производительности масштабной воздушной войны.
- Вручную просмотрены контрольные кадры компактной экономики, выбора страны, авиации, конструктора, производства и армии, включая 720p. Это не заменяет длительное игровое балансирование и проверку на реальном Windows.

## Измерение карты

1600×900, Mono/Xvfb, полный атлас под боковыми панелями:

| Операция | Среднее время |
|---|---:|
| Обычный кадр, 30 кадров | 6,3 мс |
| Перетаскивание кэшированной карты, 20 кадров | 6,5 мс |
| Принудительная полная перестройка с запасом 128 px, 12 кадров | 93,7 мс |

Открытие панели, смена выделения и короткое перемещение внутри запаса не перестраивают географию. Полная растеризация после большого скачка остаётся синхронной. Значения — отдельный локальный прогон; полный атлас 0.5 шире карты 0.4, поэтому эти цифры нельзя выдавать за чистое сравнение одинаковых областей рисования.

Точные результаты: `tests-sdk.txt`, `ui-results.txt`, `build-sdk.txt`, `legacy-save.txt`, `simulation-performance.txt`. SHA-256 проверенного exe и исходных файлов: `build-receipt.json`. Упаковщик требует совпадения хешей, наличия исполненных проверок и нулевого числа ошибок.
