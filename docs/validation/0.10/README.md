# Проверки Sovereign 0.10

Проверен именно `bin/Release/net472/Sovereign.exe`, собранный .NET SDK 8.0.426 / Release net472 без ошибок и предупреждений. Исполнение — Debian 13 / Mono 6.12 / libgdiplus / Xvfb. Реальный Windows 10/11 и удалённый GitHub Actions в этой сессии не проверены. Хеши исполняемого файла и соответствующих исходников: [build-receipt.json](build-receipt.json).

## Функциональные результаты

- **406 проверок логики**, `Failures: 0`. Все прежние системы, нейтральные доктрины новой кампании, точная разовая оплата, атомарный отказ для недоступной ступени, один курс, ежедневный прогресс, пауза, отсутствие финансирования/образования/территории, отмена без возврата и 18 достижимых ступеней.
- Переучивание проверено на точных границах 29/30 и 179/180 дней. Армия и авиация независимы; освоение альтернатив не даёт скрытого суммирования. Научная работа продолжает выполняться параллельно с подготовкой штаба.
- Реальные приказы и симуляция подтверждают скорость перехода, наземное топливо, содержание, автономность, людские потери, восстановление организации, атаку и оборону. Авиационные тесты выполняют настоящие вылеты: расход топлива, разведку, удар, доставку груза, содержание в резерве и истребительное прикрытие. Тест перехвата использует 35% готовности истребителя, чтобы не упираться в существующий предел потерь за вылет.
- **407 проверок интерфейса**, `Failures: 0`. Настоящие события мыши WinForms; все 18 ступеней нажаты при 1280×720, 1600×900 и 1920×1080. Проверены границы и отсутствие пересечения кнопок, переходы к технологиям, начало/пауза/отмена курса, выбор школы и возврат к науке. Ответы подтверждений задаются тестовым обработчиком: проверены принятие и отказ, но внешний вид системного диалога не проверялся.
- Состояние курса и переучивания сохраняется побайтово; два экземпляра остаются одинаковыми через 150 дней после загрузки. Повреждённые уровни, принадлежность школы роду войск, отсутствие предпосылок, нечисловой прогресс, неправильная оплата и массивы отклоняются без замены текущей кампании.
- Формат 8 мигрирует в 9 без изменения научного прогресса, денег и RNG и без бесплатных доктрин. Исходное пользовательское сохранение из ZIP и сохранение 0.9 с расширенной наукой загружены и продолжены на 30 дней; оригиналы не перезаписаны. XML-файлы тестов и личные сохранения в Git и релиз не входят.
- Двухлетний сценарий подтверждает оплату, обучение и применение доктрин странами ИИ. Пятилетний общий сценарий: `1825 days, 176 countries, 4136 provinces, 575 formations: 6.15 seconds`. Его время получено одновременно с функциональными UI-проверками и не используется для сравнительного вывода о скорости.

## Производительность

Один отдельный запуск `--benchmark` после окончания функциональных задач, размер 1600×900. Это CPU-время ввода и отрисовки под Mono, **не измерение отображаемого FPS на Windows**. В этом релизе не проводилось контролируемое сравнение до/после; числа не доказывают ускорение относительно 0.9.

| Сценарий | Среднее, мс | p95, мс | Максимум, мс |

| Кэшированный политический кадр | 3.37 | 3.77 | 4.71 |
| Наведение с точным попаданием | 3.63 | 4.18 | 6.00 |
| Выделенная сложная область | 12.77 | 13.23 | 13.95 |
| Перетаскивание карты | 3.44 | 3.81 | 4.30 |
| Полная перестройка карты | 34.33 | 36.72 | 36.95 |
| Ресурсный слой при смене дня | 5.94 | 12.01 | 18.87 |
| Научная ведомость | 6.08 | 6.60 | 7.01 |


Полный отчёт: [performance.txt](performance.txt). Синтетическая строка «Seven-day simulation burst» измеряет семь последовательных тиков для диагностики; рабочий UI-таймер по-прежнему выполняет максимум один день за вызов. Полная перестройка карты остаётся дороже сохранённого кадра. Большие войны, другие машины и реальный Windows требуют отдельного профилирования.

## Воспроизведение

```bash
# Собрать Release .NET SDK 8, затем выполнить именно получившийся exe.
dotnet build Sovereign.csproj -c Release
source /workspace/tooling/env.sh
mono bin/Release/net472/Sovereign.exe --test artifacts/test-sdk-0.10/tests-sdk.txt
bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --ui-test artifacts/ui-sdk-0.10
# Отдельно, после завершения других тяжёлых задач:
bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --benchmark artifacts/performance.txt
```

`scripts/package.py` сверяет SHA-256 exe и исходников с квитанцией проверки, требует успешные отчёты и проверяет CRC архива. Это не завершение всего ТЗ; оставшиеся механики перечислены в [REQUIREMENTS-STATUS.md](../../REQUIREMENTS-STATUS.md).
