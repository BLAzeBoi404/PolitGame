# Проверки игры

Актуальные отчёты и снимки версии 0.4: [0.4/README.md](0.4/README.md). Ниже и в корне этой папки сохранены результаты 0.3; они относятся к предыдущей сборке.

# Проверки версии 0.3

Дата: 24 октября 2026. Среда: Debian 13, Mono 6.12, libgdiplus 6.1, Xvfb; SDK .NET 8.0.426, целевая платформа .NET Framework 4.7.2.

- `build-sdk.txt`: сборка проекта через .NET SDK.
- `tests-sdk.txt`: выполненные проверки симуляции, модулей, производства, оснащения, снабжения, геометрии и сохранений; отдельный пятилетний прогон мира.
- `ui-results.txt`: клики по реальным обработчикам Windows Forms, набор из производственного склада, карта, клавиатура, 13 экранов при 1280×720, 1600×900 и 1920×1080, переключение режимов, кэш и перетаскивание.
- `legacy-save.txt`: загружено сохранение пользователя из ZIP, затем проверено 30 дополнительных дней без изменения исходного файла.
- `simulation-performance.txt`: длительность пятилетнего прогона.
- `designer.png`, `production.png`: контрольные снимки тестовой кампании.

Счётчики PASS и Failures записаны самими запущенными проверками; результаты прежней версии находятся отдельно в `docs/archive-0.2`. Скрипт установки среды выполнен и повторён; `scripts/with-display.sh` запускает и завершает собственный Xvfb.

Измерения рендеринга — программная отрисовка в Mono/Xvfb, а не FPS на Windows. Отдельно приведены тёплый кадр, полная перестройка карты и движение готового кадра при перетаскивании. Полная перестройка остаётся заметно дороже; временная подложка у открываемого края уточняется после окончания жеста. Это ограничение не скрывается средним значением быстрых кадров.

Нативный запуск на Windows 10/11 и удалённый GitHub Actions в этих локальных отчётах не проверялись. Workflow добавлен для последующих запусков; отсутствие ошибок локально не считается подтверждением удалённого CI. Интересность баланса требует ручных игровых партий.
