# Проверка SOVEREIGN 0.19

Release `net472`, .NET SDK 8.0.426: сборка без предупреждений и ошибок. Дополнительно проходит сборка через Mono. Контрольные суммы исполняемого файла, исходников, ресурсов и библиотек — в [build-receipt.json](build-receipt.json). Упаковщик проверяет, что в архив попадает именно испытанная сборка; пользовательские сохранения и настройки исключены.

Всего 1 409 автоматических проверок в трёх основных наборах. Логический прогон моделирует 821 день за 163,73 с. Игровые правила экономики и армии на этом этапе не заменялись; длительная ручная оценка баланса не проводилась.

Новые проверки проверяют реальные действия: Home выбирает область под камерой и доступную часть в ней, а при потере столицы использует подконтрольную территорию; отрасли карточки открывают управление выбранной областью; иностранная область открывает дипломатию. Скрытая карточка освобождает карту, следующий выбор возвращает её. Информационные поля не выполняют действий.

Мини-карта изменяет только координаты камеры; масштаб и выбранная область сохраняются. Отпускание перетаскивания карты над мини-картой не считается новым щелчком. Меню слоёв блокирует её ввод. Проверены границы панелей на 1280×720, 1600×900 и 1920×1080. Новая кампания начинается в 2020 году; выключение экспериментальной эпохи возвращает эту дату.

Плотность населения использует площадь сферических контуров: проверены квадрат у экватора, пересечение линии перемены дат и диапазон площади Молдовы. Изменение населения обновляет цвет и ключ кэша. Соседние плитки с общим участком имеют одинаковые затенение и текстуру: средняя ошибка RGB **0,00**. Встроены 174 флага; две территории используют коды. У значков войск небольшое пополнение, не меняющее отображаемую надпись, не создаёт новый bitmap; переход порога обновляет его. Ограничения разведки проверяются на всех восьми слоях.

Сравнение GPU и GDI+ совпало в 676 из 693 усреднённых цветовых точек (порог 97%). Для этого сравнения отключены всплывающие подсказки, чтобы снимки содержали одинаковые элементы. Отдельная проверка подтверждает, что подсказка рисуется поверх живой мини-карты. Рамка мини-карты следует за камерой с нулём пересборок HUD и загрузок текстур. Сохраняются проверки очереди ввода, ограничений разведки, безопасного завершения фонового дня и восстановления рендера.

## Панорамирование

Один внешний измеритель `scripts/military-map-probe.py` запускает оригинальный exe из архива 0.18 и окончательный exe 0.19. Военный слой, 1600×900, высокая детализация, запрошенный предел 165 кадров/с; реальные обработчики мыши и цикл сообщений. Два прохода по шесть секунд: первый и повторный. Ввод запрашивается с частотой 500 Гц, одновременно в очереди находится не более одного события. Прогоны выполнялись последовательно, после функциональных тестов.

Стенд: Linux, Mono, Xvfb, **Mesa llvmpipe**, два потока программной растеризации. Это интервалы презентации в виртуальном окне, не FPS физического монитора. Для каждой пары режима/версии выполнен один прогон; отдельный выброс не исключается из отчёта.

| Масштаб 45, пауза, повторный | 13,50 / 14,39 / 17,98 | 13,88 / 14,86 / 33,00 |

В средней сцене число известных групп уменьшилось с **25 до 10**, без потери личного состава. На обзорной осталось пять. Во всех повторных проходах обеих версий — ноль новых плиток и ноль возвратов к обзорному атласу. На паузе также ноль пересборок HUD и загрузок текстур: мини-карта не добавляет их при движении.

В живом повторном проходе 0.19 выполнила 44 сборки HUD и 45 загрузок текстур против 33 и 54 у 0.18; за весь прогон продвинулась на 74 против 68 дней. Обе версии один раз вернулись из панели события. Улучшение живого прогона не означает одинаковой нагрузки симуляции в каждый момент или доказанного ускорения всех сценариев.

**На паузе общее ускорение не подтверждено.** Повторный обзор 0.19 оказался медленнее, с максимумом 54,89 мс; самый долгий обмен буферов занял 54,51 мс, отправка GPU-команд — не более 1,98 мс. В этой сцене не было пересборок карты/HUD или новых загрузок. Это локализует наблюдаемый выброс в презентации программного OpenGL, но не доказывает причину рывков на машине пользователя.

Первый проход средней сцены 0.19 использовал резервный обзорный атлас 11 раз на паузе и 10 при симуляции (0.18 — ноль). В обзоре: шесть против трёх. Детальная растеризация остаётся асинхронной; мгновенная готовность всех деталей при произвольном перемещении не заявляется. Карта получает затенение в фоновом кэше, а новые территории могут сначала показываться обзорным изображением. Нужна последующая проверка Windows с физической видеокартой; обещания аппаратных 60–165 FPS по этим результатам не делаются.

## Воспроизведение

```bash
source /workspace/tooling/env.sh
bash build.sh
DOTNET_CLI_HOME=/workspace/tooling/dotnet-home NUGET_PACKAGES=/workspace/tooling/nuget /workspace/tooling/dotnet/dotnet build Sovereign.csproj -c Release
mono bin/Release/net472/Sovereign.exe --test artifacts/logic-0.19/tests-sdk.txt
bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --ui-test artifacts/ui-0.19
MESA_SHADER_CACHE_DIR=/tmp/sovereign-mesa-cache LP_NUM_THREADS=2 bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --gpu-test artifacts/gpu-0.19
python3 scripts/military-map-probe.py artifacts/probe/Probe.cs
python3 scripts/military-map-probe.py artifacts/probe/Overview.cs --overview
```

Сборка внешнего измерителя описана в начале `scripts/military-map-probe.py`. Передавайте абсолютные пути к exe и отчёту, `--165`, затем отдельный прогон с `--live`. Не запускайте измерения одновременно с тестами. Native Windows и аппаратный OpenGL в этой среде не проверялись.
