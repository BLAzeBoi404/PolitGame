# Проверки версии 0.12

Проверен итоговый SDK exe: **542 проверок логики и 508 интерфейса**, ошибок нет. Сборка Release net472 без предупреждений. Выполнение: Mono/libgdiplus/Xvfb; настоящий Windows и его FPS не проверены.

Проверены контракты, оплата, материалы, занятые мощности и недельный учёт заводо-дней, поставки и обслуживание транспорта, эмбарго, боевые порядки, звёзды, сохранения и миграции. Старое пользовательское сохранение и сохранение версии 0.11 продолжены на 30 дней без перезаписи оригиналов.

Интерфейс проверен при 1280×720, 1600×900 и 1920×1080. Проверены реальные события мыши, фоновые обновления карты во время удержания мыши, быстрые перемещения и масштабирование, настройки экрана, восемь классов чертежей и пустой действующий каталог. Ответы подтверждений задавались тестовым обработчиком; внешний вид нативных диалогов требует ручной проверки.

## Производительность

[До](performance-before.txt) и [после](performance-after.txt): последовательные запуски без параллельных тяжёлых тестов, 1600×900. База — исходники 0.11 с расширенным измерительным модулем, обе сборки SDK. Текущая версия использует высокое качество в разрешении экрана. Это ограниченный диагностический замер CPU, не доказательство частоты кадров на пользовательском Windows.

Обновление кеша теперь запрашивает фоновую работу: время соответствующего кадра не равно полному времени подготовки карты. При резком переносе камеры временно виден общий атлас с меньшей детализацией; снимок async-map-during-drag.png показывает этот момент. В старой версии длительное перетаскивание могло показывать пустые полосы, поэтому сравнение скорости такого перетаскивания не означает одинаковое качество картинки.

Хеши сборки и исходников: [build-receipt.json](build-receipt.json). Полные отчёты включены. Ограничения механик описаны в [изменениях](../../CHANGES-0.12.md); всё ТЗ ещё не закрыто.
