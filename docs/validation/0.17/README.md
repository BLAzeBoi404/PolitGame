Контрольные суммы исполняемого файла, исходников и библиотек — в [build-receipt.json](build-receipt.json). Архив содержит именно проверенный SDK-файл; упаковщик сверяет его и исходники перед выпуском.

## Прокрутка военного слоя

Исходный архив 0.16 извлечён без пересборки, проверен его SHA-256. Один и тот же `scripts/military-map-probe.py` использует существующий цикл ввода/презентации, включая реальный обработчик перетаскивания. Военный слой, 1600×900, высокая детализация, масштаб 45, запрошено 165 кадров/с, ввод до 500 событий/с с объединением очереди. Два прохода по шесть секунд: первый и повторный. Все сравнения выполнялись последовательно, без параллельных тестов.

Стенд: Linux, Mono, Xvfb, **Mesa llvmpipe — программный OpenGL**, два потока растеризации. Это интервалы презентации в виртуальном окне, **не частота физического монитора**. Приведены наблюдения одного прогона на режим; они не являются устойчивой аппаратной гарантией.

| Повторный проход | 0.16 | 0.17 |
| --- | ---: | ---: |
| Пауза: средний интервал, мс | 22,81 | 18,43 |
| Пауза: p95 / максимум, мс | 29,85 / 39,53 | 19,57 / 21,69 |
| Симуляция 7×: средний интервал, мс | 22,84 | 20,30 |
| Симуляция 7×: p95 / максимум, мс | 39,28 / 53,61 | 31,42 / 78,83 |
| Симуляция 7×: интервалы >33 мс / >50 мс | 26 / 2 | 12 / 4 |
| Симуляция 7×: загрузки изображений в GPU | 245 | 51 |
| Симуляция 7×: сборки мусора поколения 0 | 42 | 8 |
| Повторный проход: новые плитки / возвраты к обзорной карте | 0 / 0 | 0 / 0 |

На паузе в повторном проходе обе версии выполняли ноль загрузок изображений и ноль перестроений HUD. В 0.17 с работающей симуляцией нет постоянного сброса плиток от небольших пополнений. p95 улучшился, однако максимальная отдельная задержка в живом режиме выросла; соответствующий максимальный swap составил 78,26 мс. Нельзя утверждать, что все рывки устранены. Переходы событий, обновления HUD и системная презентация по-прежнему создают задержки. Физические 60–165 FPS требуют отдельного замера на Windows и реальном драйвере пользователя.

Полные результаты: [0.16 пауза](map-0.16-paused-165.txt), [0.17 пауза](map-0.17-paused-165.txt), [0.16 симуляция](map-0.16-live-165.txt), [0.17 симуляция](map-0.17-live-165.txt). В отчётах сохранены также первый проход, число действительно меняющихся кадров, дни кампании и число событий; ничего не отбрасывалось из-за медленного результата.

## Цена симуляции

Три последовательные пары исходная 0.16 / окончательная 0.17. Неизменённый `scripts/SimulationProbe.cs`, Украина, 2026 год, обычная сложность, все страны и области, 35 дней прогрева и 730 измеряемых дней, без UI и автосохранения. В таблице — средние показателей трёх прогонов; полные отчёты `simulation-0.16-1..3.txt` и `simulation-0.17-1..3.txt` находятся рядом.

| Расчёт дня, мс | 0.16 | 0.17 |
| --- | ---: | ---: |
| Все дни: среднее | 8,136 | 9,233 |
| Все дни: медиана | 5,558 | 6,912 |
| Все дни: p95 | 18,712 | 19,869 |
| Недельное сведение: медиана | 15,591 | 17,083 |
| Прочие дни: медиана | 5,437 | 6,506 |

Средняя цена симуляции увеличилась примерно на 13,5% (1,10 мс/день). Это измеренная дополнительная работа, а не ускорение движка. Новые подготовка, разведка и решения ИИ меняют ход кампании: итоговое число соединений 3720 в 0.16 и 3755 в 0.17. Поэтому сравнение не изолирует стоимость одной функции. В GPU-режиме расчёт дня остаётся вне потока окна; перемещение камеры его не запускает.

## Воспроизведение

```bash
source /workspace/tooling/env.sh
bash build.sh
DOTNET_CLI_HOME=/workspace/tooling/dotnet-home NUGET_PACKAGES=/workspace/tooling/nuget /workspace/tooling/dotnet/dotnet build Sovereign.csproj -c Release
mono bin/Release/net472/Sovereign.exe --test artifacts/logic/tests-sdk.txt
bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --ui-test artifacts/ui
MESA_SHADER_CACHE_DIR=/tmp/sovereign-mesa-cache LP_NUM_THREADS=2 bash scripts/with-display.sh mono bin/Release/net472/Sovereign.exe --gpu-test artifacts/gpu
```

Для сравнения военного слоя инструкции находятся в `scripts/military-map-probe.py`; для расчёта дней — в `scripts/SimulationProbe.cs`. Тайминги запускаются после завершения остальных проверок. Native Windows, физическая видеокарта и удалённый CI в этой среде не проверялись. Полное ТЗ и исторически достоверные рейтинги частей не заявляются.
