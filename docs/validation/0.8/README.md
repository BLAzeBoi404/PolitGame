# Проверки Sovereign 0.8

Проверен именно `bin/Release/net472/Sovereign.exe`, собранный .NET SDK 8.0.426 без ошибок и предупреждений. Исполнение — Debian 13 / Mono 6.12 / libgdiplus / Xvfb. Реальный Windows 10/11 в этой сессии не использовался; локальные результаты не означают прохождение удалённого GitHub Actions.

- **314 проверок логики**, `Failures: 0`. Прежние системы продолжают проходить проверки. Новые сценарии проверяют достижимость всех 24 технологий, предпосылки, сохранение и восстановление прогресса, паузу, нулевой бюджет, однократное завершение, очередь из четырёх работ, прогноз предпосылок, удаление и блокировку очереди, автоматический запуск без второго недельного тика, модульные открытия и независимость старых проектов.
- Проверены реальные выпуск и потребление продовольствия, электричества, топлива и стали; темп сборки и сталь на комплект; срок и цена новых строек и аэродромов; исследовательский бонус; рост населения; набор, оплачиваемое пополнение, наземные и авиационные потери; суточное наземное топливо, автономность, расход топлива на вылет и эффект разведки. Тестовые открытия выданы с полным набором предпосылок. Последствия сравниваются между одинаковыми кампаниями.
- **237 проверок интерфейса**, `Failures: 0`. Настоящие события мыши и клавиатуры WinForms. Новые сценарии открывают научную ведомость, запускают и переключают исследование, восстанавливают прогресс, ставят на паузу, переходят по перекрёстной предпосылке, составляют и удаляют очередь, проверяют недоступный проект и переход из конструктора. Шесть отраслей и три вкладки проверены в размерах 1280×720, 1600×900 и 1920×1080.
- Полная кампания с активной прикладной программой, паузой, очередью и отложенным прогрессом сохраняется и загружается побайтово одинаково; после снятия паузы и следующих 150 дней обе копии остаются одинаковыми. Невозможные предпосылки, сохранённый прогресс и номера проектов отклоняются без замены текущей кампании.
- Исходное пользовательское сохранение из ZIP и реальное тестовое сохранение версии 0.7 загружены, мигрированы и продолжены на 30 дней. Исходные файлы не переписывались. Отдельный сценарий миграции формата 6 проверяет сохранение денег, RNG, активного прогресса и всех прежних модульных лимитов без выдачи прикладных открытий.
- Двухлетний сценарий подтверждает, что ИИ завершает реальные прикладные исследования и сохраняет валидные планы. Многолетний сценарий: `1825 days, 176 countries, 4136 provinces, 583 formations: 6.79 seconds`. Это встроенный сценарий, не предел производительности масштабной войны.
- Вручную просмотрены дерево с четырьмя предпосылками, фундаментальные отрасли и очередь, включая 720p. Длительное ручное балансирование и проверка на Windows остаются отдельными задачами.

Полная перестройка после большого перемещения камеры остаётся синхронной. Замеры сделаны в облачной среде с параллельными проверками и не являются контролируемым сравнением версий.
