# Проверки Sovereign 0.6

Проверен именно `bin/Release/net472/Sovereign.exe`, собранный .NET SDK 8.0.426 без ошибок и предупреждений. Исполнение — Debian 13 / Mono 6.12 / libgdiplus / Xvfb. Реальный Windows 10/11 в этой сессии не использовался; удалённый GitHub Actions не считается пройденным по локальным результатам.

- **206 проверок логики**, `Failures: 0`: прежние экономика, производство, оснащение, договоры, фронты, авиация и сохранения; дополнительно баланс личного состава, реальные потери, платное пополнение, призыв и ограничения промышленности, военные условия и задержки законов, штаты, организация, обучение, перестройка, расформирование и экипажи. Проверены отсутствие списаний при нехватке ресурсов, сохранение отрицательной казны при невозможности пополнения, возврат только уцелевшей техники и запрет повторного возврата. Боевой вес, топливо и содержание проверены для разных размеров частей. Двухлетняя военная симуляция проверяет баланс людей у всех стран.
- **162 проверки интерфейса**, `Failures: 0`: настоящие события мыши и клавиатуры WinForms; три разрешения (1280×720, 1600×900, 1920×1080); прежние карта, атлас выбора страны, компактные панели, фронты и авиация. Новые проверки нажимают кнопки смены призыва, выбора и создания штата и набора части, затем проверяют реальные расходы денег, людей и трёх комплектов техники. Границы новых панелей проверены на всех трёх разрешениях. Подтверждение перестройки отдельно не автоматизировано; операция проверена на уровне движка.
- Исходное пользовательское сохранение из ZIP загружено, мигрировано и продолжено на 30 дней. Также продолжено на 30 дней сохранение предыдущей версии 0.5 с авиацией, созданное её тестами. Исходные файлы не перезаписывались. Проверены миграция в формат 5, отказ при повреждении кадрового баланса и идентичность продолжения после сохранения/загрузки, включая дробные остатки потерь.
- Многолетняя проверка: **1825 дней, 176 стран, 4136 областей, 565 наземных частей — 3,68 с** на этом хосте; итоговое состояние проходит полную валидацию. Это измерение встроенного сценария, а не предел производительности масштабной войны.
- Вручную просмотрены контрольные кадры резерва и подробного списка частей, включая 720p. Это не заменяет длительное игровое балансирование и проверку на реальном Windows.

## Измерение карты

1600×900, Mono/Xvfb, полный атлас под боковыми панелями:

| Операция | Среднее время |
|---|---:|
| Обычный кадр, 30 кадров | 6,7 мс |
| Перетаскивание кэшированной карты, 20 кадров | 6,5 мс |
| Принудительная полная перестройка с запасом 128 px, 12 кадров | 97,2 мс |

Сеть снабжения теперь рассчитывается один раз за день и используется и пополнением, и движением частей. Кэш географии сохраняется при открытии панели и коротком перетаскивании. Полная растеризация после большого скачка остаётся синхронной. Значения — отдельный локальный прогон; их нельзя считать чистым сравнением производительности версий с разным состоянием симуляции и нагрузкой хоста.

Точные результаты: `tests-sdk.txt`, `ui-results.txt`, `build-sdk.txt`, `legacy-save.txt`, `previous-release-save.txt`, `simulation-performance.txt`. SHA-256 проверенного exe и исходных файлов: `build-receipt.json`. Упаковщик требует совпадения хешей, наличия исполненных проверок и нулевого числа ошибок. Генерируемые XML-сценарии находятся только в игнорируемой папке `artifacts/`.
