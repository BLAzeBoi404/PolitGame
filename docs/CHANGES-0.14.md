# SOVEREIGN 0.14 — GPU-карта и независимый расчёт дня

Карта кампании и карта выбора страны теперь выводятся через OpenGL на Windows. География хранится в текстурах; движение камеры переиспользует её вместе с панелями, маркерами и подписями. Непросмотренные участки готовятся в фоне, соседние текстуры предзагружаются. Пока детализация не готова, остаётся обзорная подложка.

Расчёт игрового дня в GPU-режиме вынесен из потока окна. Перемещение и масштабирование используют последнее готовое состояние; приказы и сохранение ожидают завершения текущего дня. При закрытии игра завершает расчёт перед освобождением ресурсов. Формулы симуляции и формат сохранения 12 не изменены; существующие кампании подходят.

В настройках добавлена отрисовка «Видеокарта (авто) / Совместимая». Доступны лимиты 144/165/240 и режим «По частоте монитора»; новое окно по умолчанию использует частоту монитора. При ошибке OpenGL включается совместимый режим. В архиве теперь есть две обязательные библиотеки OpenTK: распаковывайте всю папку, не переносите только exe.

Изучены открытые реализации MapLibre GL JS и OpenTTD. [Архитектура, источники, бюджеты и ограничения](RENDERING.md). [Результаты проверок](validation/0.14/README.md).

Облачные проверки используют программный Mesa на Linux. Новый путь не означает автоматически подтверждённые 165 FPS на пользовательской RTX: Windows и аппаратный драйвер здесь недоступны. Перестройка панелей, новый большой слой и драйверная загрузка текстур всё ещё могут влиять на время кадра. Полное игровое ТЗ этой версией не закрывается.
